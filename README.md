## 📖 About The Project

**HEXAI-All-in-One** is engineered to bridge the gap between fragmented artificial intelligence models and developer productivity. Whether you are looking to orchestrate multi-agent pipelines, leverage state-of-the-art NLP models locally or via cloud wrappers, or script complex data workflows, HEXAI packages it into an accessible, high-performance ecosystem.

## 🚀 Getting Started

### Prerequisites

- **Python 3.10+** or **Node.js 18+** (depending on your environment preference)
- **Docker** *(optional, for containerized deployments)*

### Installation

**1 — Clone the repository**

```bash
git clone https://github.com/HexSleuth/HEXAI-All-in-One.git
cd HEXAI-All-in-One
```

2 — Configure environment

```bash
cp .env.example .env
# ✏️ Edit .env and insert your API keys and configuration parameters
```

3 — Install dependencies

```bash
# Python
pip install -r requirements.txt

# OR — Node.js
npm install
```

4 — Run it

```bash
# Python
python main.py

# OR — Node.js
npm run start
```
